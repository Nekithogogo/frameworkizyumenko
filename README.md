# CertHub — сервис управления SSL-сертификатами

Консольное приложение для учета доменов и выпущенных для них
SSL-сертификатов с контролем сроков действия.

## Назначение

CertHub помогает вести учет SSL-сертификатов: для каких доменов они
выпущены, какой организации принадлежат и когда истекает их срок
действия. Сервис заранее предупреждает об истекающих сертификатах,
чтобы сайт не остался без защищенного соединения.

## Целевая аудитория

Системные администраторы и DevOps-инженеры компаний, у которых много
доменов, а также сотрудники хостинг-провайдеров и удостоверяющих центров,
сопровождающие сертификаты клиентов.

## Предметная область

Организация владеет доменами. Для домена выпускается SSL-сертификат
определенного типа (DV, OV, EV) на ограниченный срок.

Правила предметной области:

- срок действия сертификата — от 1 до 398 дней;
- у домена не может быть двух неотозванных сертификатов с пересекающимся
  сроком действия;
- за 30 дней до окончания срока сертификат считается истекающим;
- продление — это выпуск нового сертификата, начинающего действовать
  на следующий день после окончания старого;
- отозванный сертификат не защищает домен и не мешает выпуску нового.

## Основные сущности

- **Сертификат** — серийный номер, тип (DV/OV/EV), домен, признак отзыва;
- **Домен** — доменное имя, например `shop.example.ru`;
- **Организация** — владелец доменов (на ПР2 хранится названием в домене);
- **Срок** — период действия сертификата: `valid_from` и `valid_to`.

## Возможности

- просмотр доменов, поиск по имени, отбор по зоне или организации;
- добавление доменов с проверкой доменного имени;
- просмотр сертификатов, упорядоченных по дате окончания, со статусом
  (еще не действует, действует, скоро истекает, истек, отозван);
- проверка срока действия сертификата домена;
- выпуск, продление и отзыв сертификатов;
- список сертификатов, требующих продления;
- хранение данных между запусками в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска, меню и пользовательские сценарии;
- `domains.py` — функции работы с доменами;
- `certificates.py` — функции работы с сертификатами и сроками;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — безопасный ввод чисел, строк, дат и вариантов;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.

Функции из ПР1 (`is_valid_term()`, `get_expiry_date()`, `get_days_left()`,
`get_certificate_status()`) сохранены в `certificates.py` и используются
в новых функциях.

## Формат данных

`data/domains.json` — список доменов:

```json
[
    {"id": 1, "name": "example.ru", "owner": "ООО «Ромашка»"}
]
```

`data/certificates.json` — список сертификатов, даты в формате ГГГГ-ММ-ДД:

```json
[
    {
        "id": 1,
        "serial_number": "CH-000001",
        "cert_type": "OV",
        "domain_id": 1,
        "valid_from": "2026-03-01",
        "valid_to": "2027-03-01",
        "is_revoked": false
    }
]
```
